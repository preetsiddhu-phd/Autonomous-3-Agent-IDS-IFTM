# 🛡️ Autonomous 3-Agent IDS - IFTM IoT Lab
**PhD Research Prototype | Latency 78ms | Accuracy 96.2% | Edge AI Ready**

### 🚀 Live Demo
**Streamlit Dashboard:** https://preetsiddhu-phd-autonomous-3-agent-ids-iftm-app-ip3cdy.streamlit.app/

### 🧠 Architecture - 3 Autonomous Agents
- **Agent 1 - Detector Agent:** Real-time DDoS/Botnet detection using LSTM-CNN
- **Agent 2 - Explainer Agent:** SHAP-based Explainable AI for threat reasoning
- **Agent 3 - Mitigator Agent:** Autonomous mitigation via iptables firewall rules

### 📊 Key Features
- Real-time detection with 78ms latency
- 96.2% accuracy on IoT-23 dataset
- Raspberry Pi 5 deployable
- Fully autonomous response
